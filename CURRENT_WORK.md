# Current work

**Feature:** F21 – Installable as an app (PWA)
**Status:** in progress
**Started:** 2026-08-25

## Goal

The household can install KassenKnoten from the browser and open it like a native app —
own icon on the home screen or in the app list, no address bar, straight into the
dashboard. Every browser that can install a web app offers it; the ones that cannot are
told, in German, what to do in their own menu instead of being left with a dead button.

## Scope

- In: web app manifest, app icons (incl. maskable and Apple touch icon), a service worker
  that makes the app installable and gives it an offline screen, `appleWebApp` metadata
  for iOS, an "Als App installieren" card in `/einstellungen` that adapts to the browser,
  the CSP and public-path changes this needs, a regenerable icon script.
- Out: offline editing, background sync, push notifications, caching of any household
  data. The app stays online-only; the service worker exists to make it installable and
  to explain the absence of a connection, not to fake one.

## Notes / decisions

- **Nothing personal is ever cached.** Every page in this app is server-rendered money
  for one household. A service worker that cached HTML would put balances into a store
  that survives sign-out and is trivially readable on a shared device, and it would show
  yesterday's figures as if they were today's. The worker therefore has an allowlist of
  three things — the offline screen, the icons, and content-hashed `/_next/static/`
  assets — and passes everything else straight to the network.
- `script-src` carries `'strict-dynamic'`, which makes browsers ignore `'self'` in that
  directive. `worker-src` falls back to `script-src`, so without an explicit
  `worker-src 'self'` the CSP would block the service worker.
- Chromium fires `beforeinstallprompt`; Safari and Firefox never will. Rather than hiding
  the card there, it names the menu path for that browser — installing is a browser
  feature, and the app's job is to say where it lives.
